# huber-robust-regression
A small numerical study of robust regression. Least squares is dominated by a handful of outliers; the Huber loss stays quadratic near zero but grows only linearly in the tails, which brings the parameter estimation error down from 59.5 to 5.6 on the same data. This repository implements the Huber loss and its matrix-form gradient, checks that gradient against central finite differences across several step sizes, and tracks where each check stops being meaningful — including the point at which a residual crosses the Huber threshold and the second-order remainder stops being quadratic.
